## 🚀 快速开始

### 查看文章

直接访问 GitHub Pages：https://rieckoio.github.io/my-blog/

### 构建新文章

```bash
# 1. 在 posts/ 目录创建 Markdown 文件
vim posts/new-article.md

# 2. 构建 HTML
node build-posts.js

# 3. 提交并推送
git add .
git commit -m "Add new article: new-article"
git push origin main

# 4. 等待 1-2 分钟，文章自动发布
```
